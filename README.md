# rotex-shader

Shader crates for Rotex.

| Package | Path |
|---------|------|
| `rotex-shader-core` | `crates/rotex-shader-core` |
| `rotex-shader-cooker` | `crates/rotex-shader-cooker` |

`rotex-shader-cooker` depends on `rotex-shader-core` by path inside this repo. Both depend on published `rotex-types`. Each package keeps its own version and its own release tag.
